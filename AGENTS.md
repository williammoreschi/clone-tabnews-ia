# AGENTS.md - Contexto do Projeto `clone-tabnews-ia`

## Visão Geral
O **`clone-tabnews-ia`** é uma implementação do [TabNews](https://www.tabnews.com.br) (baseado no curso.dev de Filipe Deschamps), desenvolvida com o auxílio de agentes de IA.

## Stack e Arquitetura
- **Runtime:** Node.js `v22` (definido em `.nvmrc`)
- **Framework Web:** Next.js utilizando o **App Router** (diretório `app/`)
- **Biblioteca UI:** React
- **Idioma padrão da aplicação:** Português (`pt-BR`)

## Comandos Principais
- `npm run dev`: Inicia o servidor de desenvolvimento (`next dev`)
- `npm run build`: Gera o build de produção (`next build`)
- `npm run start`: Inicia o servidor de produção (`next start`)
